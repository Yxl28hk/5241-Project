# Student course tutoring

To reuse the configured teacher Claude Messages service, set `TUTOR_USE_STUDIO_AI=1` in the local `.env` and restart Flask. The existing `STUDIO_AI_BASE_URL`, `STUDIO_AI_API_KEY`, and `STUDIO_AI_MODEL` configuration (or explicitly configured local credential file) remains server-side. No credentials are returned to the browser. Alternatively keep the flag off and configure the existing independent `TUTOR_API_URL`, `TUTOR_API_KEY`, and `TUTOR_MODEL` adapter.

Live questions use the selected published course's sections, objectives, example, task, checklist, and extracted PDF/PPTX attachment text. The attachment is resolved from the database, never from a client-supplied filename or URL. Course materials are data rather than instructions. The prompt asks for source page references and explicit acknowledgement of missing facts. References generated by the model still require human checking; they are not a factual accuracy guarantee.

Extraction supports up to 20 MB, 60 pages/slides and 45,000 characters. No OCR, full image understanding, audio or video transcription is provided. Missing, unsupported or unreadable attachments produce a visible reading notice; available published text remains usable. No other course, private notebook or unpublished teacher draft is added to context. Each request re-reads the current published material, so updated attachments and course edits are reflected on subsequent questions.

The student sees a disclosure before asking, a live AI label, reading limitations, and saved conversation history. Provider errors remain explicit, with manual retry or guided-card fallback. Fixed exercise grading and game mechanics are unchanged. Generated practice questions in chat do not create a persistent quiz bank.

Local verification on 23 November 2026 used a clearly labelled fictional Lantern handout: the provider correctly identified a 3% error threshold lasting 7 minutes and two reviewers, with page references, and declined to invent a monthly cloud budget. This is a focused integration check, not a broad accuracy evaluation.

## Published course learning support

Teacher-authored sections and examples now expose contextual explanation buttons in the student view. The server resolves each selection against the published course; arbitrary section indices are rejected. Task hints also work for published teacher tasks. The reference action returns the teacher-authored reference directly, without using a model, and remains unavailable when none was published.

On model failure, students can explicitly choose course text / knowledge cards. Uploaded courses then show the selected published paragraph, task requirements or checklist instead of an unrelated built-in card. The interface labels this as non-AI content. No automatic quiz bank or graded AI assessment is introduced.
