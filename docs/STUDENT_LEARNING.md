# 学生学习功能交付说明

## 本期范围

沿用 Flask、PostgreSQL 与原生 HTML/CSS/JavaScript，不增加前端构建步骤。

1. **学习页面**：学生登录后默认进入“我的学习”，首屏直接展示最近课时和继续入口，隐藏宣传大图；当前路径优先展示。游客保留介绍页。全屏课时页包含目录、目标、情境、讲解、示例、任务、回顾、前后导航和助手。
2. **学习画像**：学习目标（协作/质量/工程）、自报基础（零基础/入门/有经验）、每周小时数，可跳过或清空。不会推断能力成绩。
3. **路径选择**：三条预置路径复用已有三节课，不复制学习记录；选择明确确认，切换保留历史与各路径最近位置。
4. **进度保存**：前端显示未开始/学习中/已完成，打开课时只更新位置，不自动完成；后台保留已有 50% 阅读记录。完成保存成功后显示回顾、下一节或路径完成后的实践挑战，支持重新学习及显式失败重试。
5. **路径推荐**：按目标与基础排序，零基础优先补基础；返回具体原因。未填画像时展示可选路径。画像改变只更新推荐，不替学生切换当前路径。下架导致不完整的路径不可选。
6. **学习助手**：支持段落与示例提问、两步提示与参考解析、回答存入笔记；按课时恢复最近 20 轮，新对话替换本课会话。默认知识卡，可配置真实 AI。
7. **练习与笔记**：每节一道固定练习，由服务端判定并保存最近结果；笔记和任务草稿按账号保存，支持自动同步、失败重试与多窗口版本冲突选择。

## 实现位置

- `app/learning/paths.py`：路径模板、推荐规则、学习快照和最近位置。
- `app/learning/routes.py` / `service.py` / `repository.py`：画像、路径、课时、进度、笔记与练习的接口、业务和 SQL。
- `app/tutor/` 与 `app/infrastructure/tutor_provider.py`：会话、知识卡与真实模型适配、历史验证、错误脱敏。
- `app/missions/`：任务接口、步骤校验及计分。
- `frontend/features/learning/`、`frontend/features/tutor/`、`frontend/styles/`、`frontend/index.html`：学生学习界面及响应式布局。
- `app/factory.py`、`app/infrastructure/migrations.py`、`migrations/`：应用组装、增量迁移和 CLI；`run.py` 为启动入口。

完整目录及协作分工见 [架构说明](ARCHITECTURE.md)。

## 升级与演示

已有数据库运行 `python -m flask --app run init-learning` 后重启服务。新数据库使用原 `init-db`。不需要更改已存在的账号、课程或进度。

演示顺序：注册/登录 → 完善画像 → 看推荐理由 → 查看路径目录并确认 → 学第一节并标记完成 → 打开另一课时 → 刷新后继续学习 → 切换路径 → 查看共同课时复用状态 → 向助手提问与追问。

## 本期边界

课程主题仍为 Git/PR、CI/测试、安全发布，约 5 分钟为短课阅读估计，动手时间因人而异。固定单选练习只用于自测，不作为正式考试成绩，不自动标记课时完成。任务草稿与笔记已升级为账号保存；sessionStorage 仅保留未同步内容的恢复副本。

首屏与内容结构那一轮不需要新表；第 4–7 项新增三张学习工具表，已有数据库也需再次执行 `init-learning`，然后重启服务。升级只增量创建缺失表，已有进度保留。

默认助手为规则式知识卡；真实模型需服务端配置三个 `TUTOR_*` 环境变量。会话由账号和课时隔离，刷新或切换后恢复。新功能与升级细节见 `STUDY_TOOLS.md`。
