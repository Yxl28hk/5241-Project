# 第 4–7 项学习体验增强

## 固定练习

Git/PR、CI/测试、安全发布各有一道固定单选题。获取题目时不返回答案；学生提交后由服务端判断，返回所选项解析与参考选择。可重做，按账号、课程与题目版本保存最近结果和提交次数。客户端自报的分数或正确标志不参与判定。

练习不自动创建学习完成状态，也不作为考试成绩。上传资源尚未配置固定练习时隐藏该区域。

## 路径差异与编号

路径 ID 保持 `collaboration`、`quality`、`engineering`，旧的选择记录与学习进度继续有效。

- 团队协作入门：Git/PR → CI，产出包含验证证据的 PR 交接说明。
- 测试与发布基础：CI → 安全发布，产出故障调查步骤与发布恢复清单。
- 软件工程流程体验：串联三节，再挑战 Release Rescue。

课时本身移除全局编号，路径目录、详情按各自顺序从第 1 节生成编号。旧数据库中内置课程标题由学习接口规范化显示，不需要改动课程 ID。

## 具体内容提问与提示

讲解段落和示例旁的按钮选择 `section-N` 或 `example`，服务端从当前课时取对应内容，不能由客户端传入任意正文替代。任务和练习分别使用 `task`、`exercise`。

提示 1 引导关注问题，提示 2 提供操作顺序，参考思路通过独立按钮查看。提示与参考为已编写内容，不调用模型，也不包装成实时 AI。真实模型可使用所选内容和本课最近对话进行答疑。

## 笔记与草稿

笔记最多 12000 字，任务草稿最多 4000 字。输入后约 700ms 尝试同步，切换课时、离开学习页、进入挑战或退出前先等待保存。失败时显示重试操作，并保留当前标签页的恢复副本。

每次保存携带 `revision`。多个窗口编辑同一课时会返回冲突，学生重新载入后可明确选择保留账号版本或使用本机草稿。不会静默覆盖其他窗口内容。旧版标签页任务草稿在首次没有账号草稿时可自动迁入。

## 最近课时会话

每个账号、每节课保留一份最近会话，最多 20 轮。刷新、重新登录或切换回来时恢复。新对话会替换本课会话，但不删除笔记或练习结果；助手回答可保存到本课笔记。

会话 token 与 revision 保护更新顺序；同一 request_id 的最近一次重试返回已经保存的回答，避免响应丢失后重复写入。新对话会更换 token，旧请求返回时不能覆盖它。真正的模型调用失败不写入成功对话，可重试或主动使用知识卡。

## 升级

新增 `lesson_notebooks`、`lesson_exercise_results`、`lesson_conversations`，关联账号与课程并支持级联清理。已有数据库执行：

```powershell
.\.venv\Scripts\python.exe -m flask --app run init-learning
```

随后重启服务。命令可重复执行，不清空既有账号、课程、进度或学习工具记录。直接运行 `run.py` 也包含增量初始化。

## 验证

完整自动化及浏览器结果见 `VALIDATION.md`。真实模型连通与质量仍需配置实际提供商；练习、笔记、会话、分步提示在默认知识卡模式下均可使用。
