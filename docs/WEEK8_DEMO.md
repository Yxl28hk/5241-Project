# Week 8：5–7 分钟演示

先按 README 配置 Neon 数据库和管理员密码，再运行 `python run.py`，打开 http://127.0.0.1:5000，自行注册学生和教师账号。Tutor 无需 API key；外部字体加载失败不影响功能。课程可以重置进度，完成的任务可以重新挑战，不需要清空数据库。

1. **30 秒：问题。** 普通课程平台提供材料，我们把“读课程 → 得到提示 → 工程决策”接在一起。说明保留学生、教师、管理员角色。
2. **1 分钟：路径。** 展示 Git/PR、CI、发布三课、进度和推荐下一节。推荐是透明顺序规则。
3. **1 分钟：Tutor。** 打开第一课，点“给我提示”，点“已理解 · 标记完成”。关闭后显示 1/3、33%，刷新仍保留。说明进度是自评。
4. **2 分钟：模拟。** 选择 PR；CI 步骤故意选择删除测试，展示错误解释；后两步选测试环境验证和回滚。最终应是 75 分通过。可中途刷新再点继续，展示恢复。
5. **1 分钟：团队功能。** 使用已注册的教师账号上传 PDF；学生加入并记 50%；教师在资源管理查看进度。使用环境配置创建的管理员账号查看账户和记录。
6. **30 秒：边界。** Tutor 是明确标识的规则式占位，当前任务只有四步；下一阶段接入真实模型、更多情境和教师分析。

## 常见提问

- **数据是真的吗？** 所有学习操作写入配置的 Neon PostgreSQL 数据库。
- **AI 是真的吗？** 当前规则式占位用于展示课程上下文和交互，尚未接入真实大模型。
- **如何算进度？** 学生主动确认 0/50/100%，三节课平均；任务分数独立计算。
- **防重复得分？** 后端保存当前步骤，旧步骤重复提交被拒绝。
- **下一步优先？** 独立 Neon 测试分支联调、真实 Tutor、学生试用反馈。
